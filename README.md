# Totem Highlight (Fabric, Minecraft Java 26.2)

Client-Mod. Wird dein Totem ausgeloest, werden 2 Sekunden lang alle Totems in Inventar UND Hotbar
(inkl. Offhand) mit einem pulsierenden goldenen Glow markiert; am Ende blendet er weich aus.

Dauer aendern: DURATION_MS in TotemHighlight.java.

## Mod ohne Programme herunterladen (GitHub, nur Browser)
1. Kostenlosen Account auf github.com erstellen, oben rechts "+" > "New repository", Name z.B. totemhighlight, "Create repository".
2. "uploading an existing file" anklicken, ALLE Dateien und Ordner aus diesem Projekt hineinziehen
   (auch den versteckten Ordner .github), unten "Commit changes".
3. Oben Reiter "Actions" > "Mod bauen" > nach ca. 2-5 Minuten ist der Lauf gruen.
4. Lauf anklicken, unten bei "Artifacts" totemhighlight-mod herunterladen (ZIP), darin liegt die .jar.
5. Die .jar in den mods-Ordner legen (Fabric Loader und Fabric API fuer 26.2 muessen installiert sein).
